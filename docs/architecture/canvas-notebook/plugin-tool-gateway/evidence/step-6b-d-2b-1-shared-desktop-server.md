Its immutable snapshot binds the canonical connection reference, backend, ownership, configuration/version/generation, starting metadata/grants/binding revisions, authorization revision and original human actor/workspace with the actual BetterAuth session. Start holds fresh CommonStore Manage authority and the original session row. Provider work and the state write recheck session expiry. A manager does not need Use authority to configure an account. Shared desktop uses the already registered public MCP callback. Collection checks sealed routing, exact state/issuer/snapshot, expiry and replay and saves the code encrypted. It makes zero SQL queries, token requests or binding publications, including on a cold import. Only an absent shared namespace permits personal fallback.

Status, cancellation and finalization require the original user/session/workspace/reference and current Manage authority. Finalization checks eligible state and stages the unpublished-binding execution fence. The durably acknowledged exchange-attempt marker precedes the one-time token POST. Actual sealed tokens must match the exact authorization state, connection/configuration/version/generation, server, issuer, client and resource and a valid bearer credential/lifetime. An ambiguous HTTP result or lost socket ACK without that proof fails closed; retry never replays the old code.

Binding publication and its private receipt share the caller's outer SQL transaction. The additive receipt table stores state/snapshot/session/actor hashes and exact before/after revisions, but no OAuth code, PKCE or token. Its helper opens no transaction or database lease. A locator becomes completed only after confirmed SQL COMMIT. Every transaction and owner-index write has an exact decrypted readback; a fallback write with a stale preferred file cannot falsely acknowledge an exchange marker.

At unchanged starting revisions, exact tokens allow retrying publication without another exchange. After publication, recovery also needs the exact same-flow SQL receipt, fresh original-session/Manage authority and post-publication proof. An unrelated later binding or generic authorized status cannot complete the old flow. Expiry after a committed publication may recover only through this complete proof. Pending creation is bounded to eight states per initiating user; expiry, cancellation and terminal TTL remove only their exact temporary OAuth state.
