## Client boundary

The paired `canvas-notebook-mobile` branch `codex/mobile-plugin-gateway` starts from remote main `69dad7c1`. Five explicit root capabilities independently gate shared Apps, scoped resources, shared connections, shared OAuth and workflows. Existing personal V1 fallbacks remain available on older servers.

A common scoped client captures instance, server URL, user, original authentication session and workspace. Every committed owner lifetime is unique, including A-to-B-to-A and React StrictMode recreation. Cookie preparation uses the existing authentication service; requests use the captured cookie and workspace, bounded timeouts and `credentials: omit`. Identity replacement, sign-out, offline transition and unmount permanently dispose the old client. Both request and response are fenced. Scoped requests neither refresh a rejected original session nor replay a 401 through the general authentication transport. Normalized paths cannot escape the versioned mobile API or captured origin.

Chat retains personal V1 descriptors and parses shared V2 descriptors with exact connection/source/call/resource/revision bindings inside the existing V1 App host transport. The actual MCP card caller receives the scoped client. A replacement host channel cannot act through an old A callback after A-to-B-to-A. Provider HTML receives no account cookie or private connection proof.

Shared connections disclose Organization/Team, exact source/reference, MCP backend or Composio profile and current permissions. Use and Manage remain independent. Setup requires an explicit scope/profile choice. Metadata and sharing preserve all three CAS revisions; conflicts require manual reload. Scoped OAuth stores only the sealed native intent in SecureStore before Start, opens the system authentication browser and accepts only the closed opaque integration-return scheme. Status recovery uses GET, including lost Start/finalize acknowledgements. Durable finalization state and synchronous operation locks prevent duplicate relinking or overlapping Resume browsers.

Scoped plugins/Skills disclose installed/store/update state, exact resource identity, installation scope, independent Use/Edit/Manage and sharing to organizations, workspaces and selected people. Package installation uses explicit scope, published provenance and review/CAS. Server Store state determines update availability even if a locally edited artifact has the same version as upstream. Responsibility management is independent of content editing. Existing native contracts expose presentation, not draft/script publication APIs: code editing remains explicitly directed to the Canvas Web editor without executing local code.

The agent editor and workflow panel retain exact published package revision/checksum and selected shared connection refs. Equal labels do not collapse Organization/Team or MCP/Composio alternatives. Mandatory MCP mappings require explicit confirmation. Use-only members can choose permitted shared connections or explicit personal setup. Unreadable retained bindings remain opaque and preserved. Built-in email tools retain their existing native ownership.
