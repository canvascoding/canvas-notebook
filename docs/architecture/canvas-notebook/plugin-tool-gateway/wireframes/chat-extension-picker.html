Entwurfsnotiz: Kontext im Hintergrund

Diese Notiz gehört zum Wireframe, nicht zur vorgesehenen Chat-Oberfläche. Beim echten Senden werden die im Text vorhandenen Referenzen und ihre genauen Verbindungen serverseitig geprüft. Eine zusätzliche Auswahlleiste ist nicht vorgesehen.
