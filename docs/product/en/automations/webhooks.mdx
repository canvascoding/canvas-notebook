# Webhook-Triggered Automations

A webhook automation runs when an external event arrives instead of at a scheduled time. Canvas Notebook supports custom signed webhook endpoints and connected-app triggers through the configured integration runtime.

## Create a custom webhook

Configure the name, workspace, agent, task prompt, context paths, output, skill, and delivery. Canvas Notebook returns a webhook URL and a secret beginning with `whsec_`. Store the full secret immediately; later views use a preview instead of exposing it again.

Send the secret as the bearer credential expected by the endpoint. Rotate it when it may have leaked or when the sender changes. Rotation invalidates the previous secret, so update the external service before relying on the next event.

## Use a connected-app trigger

A Composio-backed trigger binds a toolkit, connected account, trigger ID, and configuration to the automation. If the connection becomes unavailable, the trigger cannot be treated as healthy and a workspace move may be blocked.

## Treat payloads as untrusted

Webhook JSON can contain user-controlled text. The runtime labels it as external data and limits oversized event context. The saved automation prompt remains the authority; never follow instructions embedded in the payload unless the configured task explicitly requires interpreting that field.

Design for duplicate or delayed delivery. Use a stable event identifier where possible and make external side effects idempotent.
