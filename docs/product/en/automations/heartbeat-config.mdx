# Legacy Heartbeats and Workspace Automations

Canvas Notebook no longer has a separate agent-level Heartbeat setting. The old settings endpoint is retired; recurring work is configured as a workspace automation with its own prompt, agent, workspace, schedule, and delivery settings.

## What happens to an older Heartbeat

When the application encounters a legacy Heartbeat job, it migrates that job into the workspace automation system. The migration keeps its schedule, delivery target, and run history, and converts its `HEARTBEAT.md` instructions into the automation prompt. The legacy file is then removed so it is not mistaken for active agent instructions.

The old `/api/automations/heartbeat` settings API is retired and no longer configures an agent Heartbeat. You do not need to recreate a migrated job unless you want to change its behavior.

## Review recurring work

Open Automations and review the migrated job's prompt, agent, workspace, timing, and delivery target. Run it manually and inspect the result before relying on the schedule. Use a normal scheduled automation for future recurring work.
