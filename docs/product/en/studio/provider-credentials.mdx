# Studio Provider Credentials

Studio checks provider access before it starts a generation. Access can come from managed media service availability or from a locally configured API key permitted for the current user or instance.

## Provider requirements

- **Gemini image and sound:** require Gemini access.
- **OpenAI image generation and editing:** require OpenAI access.
- **Google Veo video:** requires Gemini access.
- **Bytedance video through the configured media integration:** requires Kie access.

Available models and provider mappings can change with the installed Canvas Notebook version and external services. Use the provider and model controls visible in Studio as the effective catalog.

## Configure access

An instance administrator who can manage central credentials configures managed media or central Studio credentials under AI Provider settings. A user without that authority can add permitted personal integration credentials under Settings → Integrations.

Never paste an API key into a prompt, Markdown note, Studio description, or reference metadata. Protected credential settings are designed to keep secrets out of normal workspace and chat content.

## Troubleshoot readiness

If generation is disabled, inspect the missing-provider message and verify that the selected provider has either a local key or managed access. Then confirm model compatibility, account quota, billing, region, and upstream service health. A configured key can still fail when the provider rejects the request.
