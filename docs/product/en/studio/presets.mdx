# Building Reusable Presets

A Studio preset stores a named arrangement of prompt blocks. Use presets for recurring production patterns such as a clean product shot, editorial portrait, marketplace thumbnail, or campaign key visual.

## Assemble a preset

Open the Preset Builder and choose blocks from the available block types and categories. Each block contributes a prompt fragment, label, description, and position in the preset. Add a name, description, category, tags, and optional preview image so teammates can understand the intended result.

A preset is a starting recipe, not the complete generation. The current prompt, product, persona, style, aspect ratio, provider, and model still influence the output.

## Design for reuse

Keep blocks focused on stable production decisions:

- composition and camera behavior;
- lighting and environment;
- background treatment;
- rendering or photographic style;
- negative constraints.

Do not bake a one-off client sentence or temporary campaign date into a widely reused preset. Put changing details in the generation prompt.

## Test the preset

Generate across at least two representative products or subjects. If the preset works only with the image used to create its preview, it is not yet reusable. Revise conflicting fragments and record the expected use in its description.
