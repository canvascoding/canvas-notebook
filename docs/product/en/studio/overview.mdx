# Studio Overview

Canvas Studio is the media production surface inside Canvas Notebook. It combines prompts, provider-specific controls, reusable references, generation history, bulk workflows, and workspace export for images, videos, and supported sound generation.

## The Studio workflow

1. Select image, video, or sound mode.
2. Describe the asset and choose a provider, model, aspect ratio, and output count.
3. Add product, persona, style, file, image, video, or audio references when the selected model supports them.
4. Generate and monitor the pending or generating job.
5. Review outputs, create variations, adapt ratios, favorite useful assets, or turn an image into a video.
6. Download deliverables or save selected outputs into a workspace folder.

Generations belong to the active Studio workspace. History records the raw and processed prompt, provider, model, mode, status, outputs, references, preset, creator, and timestamps needed to understand how an asset was produced.

## Reuse instead of rebuilding

Products, personas, and styles package reference images and descriptions. Presets package reusable prompt fragments. Bulk generation applies a shared setup across many product line items while still allowing selected overrides.

## Provider boundaries

Available controls depend on the selected provider and model. Image quality, transparent backgrounds, resolution, video duration, audio generation, or reference counts are not universal. Studio validates the configured access before generation and surfaces missing credential requirements.
