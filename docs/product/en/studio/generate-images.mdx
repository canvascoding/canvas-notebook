# Generating Images

Image mode creates one or more visual outputs from a prompt and optional reference material. Start with the communication goal, then describe the subject, composition, setting, lighting, style, and constraints.

## Build the request

Choose Image in Studio Create. Select a product, persona, or style when a reusable model already represents the subject. Add individual reference files for material that is unique to this generation.

```text
Editorial product photograph of the referenced notebook on a precise dark
workbench, top-left key light, generous negative space on the right, no text.
```

Choose the aspect ratio and number of outputs. Provider-specific controls may include model, quality, image size, output format, and transparent or opaque background. Only controls supported by the selected provider are sent to the generation service.

## Review variations

Open each completed output at full size. Check identity, product geometry, hands, typography, logos, crop, and prohibited content. Favorite strong candidates, download a deliverable, or create a variation using the selected output as the source.

Generated content is not automatically brand-safe or factually accurate. Reference images improve direction but do not guarantee exact reproduction. Do not request imitation of a real person or use assets without the necessary rights and consent.
