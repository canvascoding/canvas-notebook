# Excalidraw Documents

Excalidraw documents are editable visual scenes stored as workspace files. Use them for system sketches, campaign maps, storyboards, flows, and other diagrams that benefit from direct manipulation rather than prose alone.

## Create and edit a scene

Create an Excalidraw file from the Notebook and open it in the visual editor. Add shapes, connectors, text, and images, then save the scene so the underlying file remains part of the project.

Use concise labels and a consistent reading direction. A diagram should make a relationship easier to understand than the equivalent paragraph; do not turn every list into a canvas.

## Work with agents and collaborators

Canvas Notebook includes operations that allow supported agent workflows to inspect or change Excalidraw scenes. Give the agent a concrete structural request, such as adding a review step between two named nodes. Review visual output after any automated edit because spatial intent cannot be verified from file syntax alone.

When live collaboration is enabled, the editor can reflect collaboration state and may become read-only when the current participant does not have edit access.

## Share and preserve

Keep the editable scene file as the source of truth. Export a static image only for destinations that cannot render Excalidraw. Public Excalidraw views are read-only and should contain only information intended for anyone with the link.
