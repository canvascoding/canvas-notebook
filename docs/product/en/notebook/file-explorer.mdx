# Working with the File Explorer

The file explorer shows the real files and folders in the active workspace. Use it to move through a project, open documents and previews, and choose the material an agent or editor should work with.

## Organize by project and purpose

A practical structure keeps inputs separate from generated work:

```text
client-project/
  brief/
  research/
  assets/
  drafts/
  output/
```

Use descriptive names such as `campaign-brief.md` or `homepage-hero-v2.png`. Clear paths make the workspace easier for people to scan and give agents more useful context than generic names such as `final2.md`.

## Navigate and open files

Expand folders to inspect their contents, then select a file to open the matching editor or preview. Markdown and code open as editable text; supported documents and media open in specialized previews. Return to the explorer when you need to switch context or compare nearby files.

The explorer always represents the active workspace. If a file appears to be missing, first verify that you are in the expected workspace and folder before creating a replacement.

## Keep agent work scoped

When delegating a task, point the agent to a specific folder or document. A focused path reduces ambiguity and makes it easier to review what changed. Keep generated files in a dedicated output folder when you do not want them mixed with source material.
