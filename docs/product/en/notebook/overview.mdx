# Notebook Interface Overview

The Notebook is the file-first workspace inside Canvas Notebook. It brings the file explorer, document editor, agent chat, and terminal into one working surface so that people and agents operate on the same project files.

## The main areas

- **File explorer:** browse folders, create content, upload source material, and manage files.
- **Editor and preview:** edit Markdown and code or preview documents, images, media, and presentations.
- **Agent chat:** ask the active agent to inspect or change workspace material without moving it to another tool.
- **Terminal:** run commands against the same workspace when a task needs direct command-line control.

The exact panel arrangement can change with screen size and the tools you open. On smaller screens, focus on one working area at a time; on larger screens, keep source material and the agent visible together.

## A file-first workflow

Start by creating a project folder. Store the brief, research, assets, drafts, and outputs inside it. Open a document to edit it yourself, or reference the project in chat and ask the agent to help. The resulting files remain visible in the explorer and can be opened, downloaded, linked, or reused by an automation.

This model avoids a hidden split between human documents and agent context: the workspace files are the shared source of truth.

## Choose the right surface

Use Markdown for durable knowledge and briefs, the Studio for generated media, chat for delegated work, and the terminal for technical operations. All of them can contribute files to the same workspace.
