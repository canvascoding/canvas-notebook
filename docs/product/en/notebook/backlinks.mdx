# Backlinks and Linked References

Backlinks answer the reverse-link question: “Which other documents point to this file?” They are calculated from the workspace Markdown index and shown with the current document.

## Use the backlinks panel

Open a Markdown note and inspect its backlinks section. Each entry identifies a referring document. Open or preview the reference to understand the context in which the current note is being used.

For example, an `audience.md` note may have incoming references from a campaign brief, email sequence, content calendar, and reporting template. The backlinks panel reveals those dependencies without requiring you to search every folder manually.

## Review impact before editing

Backlinks are especially valuable before changing a shared definition, renaming a document, or deleting a source. Review the referring documents and decide whether each consumer still makes sense after the change.

The panel reflects indexed Markdown relations, not every possible filesystem dependency. A script, automation prompt, or code file may reference the path without creating a Markdown backlink. Search those areas separately when a path is operationally important.

## Keep the index useful

Use wiki links or normal Markdown links consistently and fix unresolved targets. A clear link graph improves backlinks for people and makes connected context easier to identify for agents.
