# PDF, Office, Media, and HTML Previews

The Notebook selects an editor or preview from the file type. This makes source material review possible without moving every document into a separate application.

## Supported workspace experiences

- **Images:** inspect common image formats at workspace resolution.
- **PDF:** browse rendered pages inside the Notebook.
- **Word documents:** open `.docx` files in the document experience.
- **Spreadsheets:** open Excel-compatible workbooks and CSV data in the spreadsheet editor.
- **Presentations:** inspect PowerPoint-compatible presentation files.
- **Audio and video:** play supported media formats.
- **HTML:** inspect source and open a rendered preview after acknowledging the content boundary.
- **Other text:** open source code and configuration in the code editor.

Format support can depend on the exact file contents, browser capabilities, and the services available in the Notebook instance. Download the original when a preview cannot represent a feature accurately.

## Preview untrusted content safely

A preview is not an endorsement that a file is safe. HTML can contain scripts or external resources, Office files can contain unsupported or complex structures, and media can reference sensitive subject matter. Canvas Notebook asks for consent around active HTML previews because rendered content has a different risk profile from plain text.

Do not use a preview as the only verification for a final deliverable. Download and inspect important files in their target environment before publishing or sending them.
