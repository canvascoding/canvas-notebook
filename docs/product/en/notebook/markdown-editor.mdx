# Creating and Editing Markdown Documents

Markdown is the primary format for durable knowledge in Canvas Notebook. A Markdown document is a plain-text `.md` file that can be edited inside the Notebook, read by an agent, processed by scripts, and opened in other Markdown tools.

## Create your first note

Create a file such as `project-brief.md` in the relevant project folder. Start with one top-level heading and use short sections for context, decisions, constraints, and next actions.

```md
# Project Brief

## Goal

Launch the new product page in September.

## Constraints

- Use the approved brand system.
- Keep the first version in English.
```

## Rich and source editing

The rich editor provides formatting controls, block actions, tables, links, images, wiki links, and a slash-command menu while continuing to store Markdown. Source mode exposes the underlying text when you need exact syntax or when a document contains constructs that the rich editor should preserve without transforming.

Changes are saved back to the workspace file. Before closing a new document, confirm that it appears at the expected path and that the latest text is visible.

## Work with an agent

Ask the agent to read or update a specific Markdown path. State whether it may rewrite the document, append a section, or only propose changes. Review the resulting diff or file contents before treating agent-generated statements as approved facts.
