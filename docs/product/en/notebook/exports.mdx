# Exporting Markdown and PDF Files

Export according to the recipient's needs. Markdown preserves editable, portable source; PDF preserves a rendered layout for review or delivery.

## Keep the Markdown source

Download the `.md` file when the recipient wants to edit, archive, version, or process the document. Relative links and images work only when their referenced assets are transferred with a compatible folder structure.

For a self-contained handoff, place the document and its assets in one project folder before downloading the required files.

## Generate a PDF

Use the document share or export view to preview rendered Markdown and request a PDF. Browser-based PDF generation must be available in the Notebook instance. If that capability is disabled, the PDF action is unavailable and you can deliver Markdown or use another renderer.

HTML files can also be rendered to PDF after the active-content preview boundary is acknowledged. Review the result because print layout, external fonts, and dynamic elements may differ from the browser view.

Marp presentations have a dedicated export flow for PDF, PNG, and JPEG slides.

## Verify before delivery

- Check headings, page breaks, tables, images, and links.
- Confirm that embedded documents contain only intended content.
- Remove internal notes and secrets.
- Use a clear filename and version.
- Retain the source file for future revisions.
