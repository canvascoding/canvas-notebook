# Wiki Links and Document Relations

Wiki links connect one Markdown document to another using a readable title or workspace path. Canvas Notebook uses these relations for navigation, backlinks, embeds, and the Document Graph. Images and other non-note files use ordinary Markdown image or link syntax instead of wiki links.

## Link a document

Use double brackets around the target:

```md
See [[campaign-brief]] for the approved scope.
```

Add a display label when the sentence should use different text:

```md
Review the [[campaign-brief|approved campaign scope]].
```

When several documents have similar names, use a more specific path so the intended target is unambiguous. The editor can help select workspace documents while inserting a link.

## Navigate links

Open a resolved wiki link to move to its target document. A link can also point to a heading or location in a Markdown file, letting a long reference document be opened at the relevant section.

An unresolved link is still useful as an explicit statement that a document should exist. The Document Graph can surface these missing targets so they can be created or corrected later.

## Keep relations maintainable

- Prefer stable, descriptive document names.
- Link to source notes instead of copying facts into many files.
- Check incoming backlinks before renaming a central document.
- Resolve accidental spelling variants before the graph becomes fragmented.
