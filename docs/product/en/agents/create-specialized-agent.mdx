# Creating a Specialized Agent

A specialized agent packages repeatable operating instructions and capabilities under a distinct identity. Create one when a workflow needs a stable role or access boundary that should not be re-explained in every chat.

## Start from a template

Open Agent Settings and choose Create Agent. Canvas Notebook includes starting templates for custom, research, coding, marketing, Studio, automation, and support workflows. A template pre-populates an icon, relevant skills, and initial managed files; it does not prevent later customization.

## Configure the agent

1. Choose a clear name and icon.
2. Select user scope for a personal agent or organization scope for a shared organizational definition.
3. Choose a default provider, model, and thinking level when the runtime catalog offers them.
4. Review `AGENTS.md`, `MEMORY.md`, `SOUL.md`, and `TOOLS.md`.
5. Enable only the tools the role needs.
6. Select relevant skills, connections, and plugins.
7. For an organization agent, configure grants and members before announcing it to the team.

## Keep the definition focused

Describe the agent's purpose, normal workflow, quality bar, and boundaries. Avoid copying a long project brief into the profile; store project-specific facts in workspace documents and reference them when needed.

Test the agent with one representative, low-risk task. Confirm that it selects the intended model, can access the right workspace, sees the expected tools, and saves outputs in the requested location.
