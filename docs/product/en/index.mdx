# What is Canvas Notebook?

Marketing work is usually scattered across document editors, cloud drives, chat tools, design software, inboxes, automation services, and a growing collection of AI tabs. The files that contain the real context live somewhere else, every tool has a different workflow, and useful decisions disappear between systems.

Canvas Notebook brings that work into one AI workspace. A hosted Notebook runs on its own VM and gives an AI agent access to the files, tools, and workflows you explicitly make available. You can write and organize documents, work with the agent in chat, produce visual assets, handle email, and schedule recurring work without moving the project through a chain of disconnected tools.

It is designed for tech-savvy freelancers, small businesses, creators, and agencies that want more leverage without giving up control of their working files. Canvas Notebook keeps the workspace understandable: content is stored as real files, agent activity is visible, integrations are scoped, and important actions can stay under human review.

## One workspace, six core capabilities

- [24/7 AI Agent](/docs/features/ai-agent) — work with an agent that can read and write workspace files, run tools, execute commands, and continue scheduled work while the Notebook instance is online.
- [Markdown Knowledge Base](/docs/features/knowledge-base) — build a connected, portable knowledge base from Markdown files, wiki links, backlinks, properties, and document relations.
- [Canvas Studio](/docs/features/studio) — generate and manage images and videos with reusable products, personas, styles, references, and presets.
- [Email](/docs/features/email) — connect inboxes, review messages, create drafts, work with attachments, and apply explicit sending policies.
- [Automations](/docs/features/automations) — turn recurring prompts into scheduled jobs, webhooks, and agent heartbeat workflows.
- [Skills and Plugins](/docs/features/skills) — extend agents with reusable instructions, executable tools, integrations, and complete plugin bundles.

## How Canvas Notebook works

Your Notebook combines a browser interface with a persistent workspace on a dedicated runtime. The application provides the editor, file browser, chat, Studio, email, automations, settings, and collaboration surfaces. The agent works against the same workspace rather than a separate upload-only knowledge silo.

You decide which model providers, tools, skills, workspaces, and connected accounts are available. A specialized agent can be limited to selected skills or granted access to specific users, projects, and workspaces. This makes it possible to create focused workflows without treating every agent as an unrestricted administrator.

## Start with one useful workflow

You do not need to configure every feature before Canvas Notebook becomes useful. Start with a single agent, create a Markdown note, and schedule one small recurring task. Add Studio, email, and custom skills when the workflow needs them.
