# System Email Configuration

System email sends platform notifications such as agent-created to-do alerts. It is separate from user-connected Gmail, Microsoft, or SMTP/IMAP inboxes and must not be treated as a user's primary mailbox.

## Required settings

Configure the SMTP host, port, secure mode, username, password, and sender address. An optional sender name and reply-to address can improve recipient handling. Enter a host name or IP address, not an `smtp://` URL; ports must be between 1 and 65535.

Canvas stores these values in the integration environment under:

```text
CANVAS_SYSTEM_SMTP_HOST
CANVAS_SYSTEM_SMTP_PORT
CANVAS_SYSTEM_SMTP_SECURE
CANVAS_SYSTEM_SMTP_USERNAME
CANVAS_SYSTEM_SMTP_PASSWORD
CANVAS_SYSTEM_EMAIL_FROM
CANVAS_SYSTEM_EMAIL_FROM_NAME
CANVAS_SYSTEM_EMAIL_REPLY_TO
```

If integration environment encryption is enabled, the stored values are encrypted with the integration master key. The UI reports whether a password exists without requiring it to be re-entered for every non-password change.
These reserved values are redacted from the general Integrations editor and can only be changed in System Email by an instance administrator.

## Configure and test

1. Create a dedicated SMTP credential with sending-only access when possible.
2. Enter settings in the administrator System Email panel.
3. Save and confirm that the configuration is complete.
4. Send a test message. Canvas delivers it to the signed-in administrator's email address, so the destination cannot be used to relay arbitrary mail.
5. Check provider logs, spam placement, sender authentication, and the received From and Reply-To headers.

Use SPF, DKIM, and DMARC for the sending domain. Do not use a personal employee password as the long-term system credential.

## Troubleshooting

Use implicit TLS for providers that require TLS from connection start (commonly port 465); use STARTTLS for port 587. Connection, greeting, and socket timeouts are limited. Provider failures return a safe error code rather than SMTP credentials or raw transport errors.

System Email has three delivery modes: local SMTP, Canvas-managed email, and disabled. Disabled deliberately suppresses system notifications and never substitutes a personal or workspace mailbox. Clearing local SMTP also selects disabled; it does not remove any user or workspace mailbox connection.
