# Understanding SKILL.md

`SKILL.md` is the required entry point for a Canvas skill. YAML frontmatter identifies the package; the Markdown body tells the agent when and how to apply it.

## Required frontmatter

```md
---
name: campaign-review
description: Review a campaign brief for missing inputs and delivery risks.
---
```

`name` must contain 1-64 lowercase Unicode letters, numbers, or single hyphens. It cannot start or end with a hyphen, contain consecutive hyphens, and it must match the parent directory name. `description` must contain 1-1,024 characters and explain both what the skill does and when to use it. The Markdown body has no format restrictions.

## Optional fields

You can add `license`, `compatibility`, `allowed-tools`, and string-valued `metadata`. No other top-level frontmatter fields are allowed. Compatibility text must contain 1-500 characters when present. `metadata` must map string keys to string values. `allowed-tools` is an experimental, space-separated string; runtime policy remains authoritative.

An optional `agents/canvas.yaml` can describe the Canvas interface with a display name, short description, icon paths, brand color, default prompt, and version.

## Instruction body

Write operational instructions in a predictable order:

1. Define when the skill applies.
2. List required inputs and preconditions.
3. Describe the workflow and decision points.
4. Explain safety boundaries and approval gates.
5. Link only to resources included in the package.
6. State what a successful result contains.

Avoid embedding secrets, user-specific paths, or claims that a tool is always available. The same skill may run for different users, agents, and workspaces.
