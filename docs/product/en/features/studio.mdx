# Canvas Studio

Canvas Studio is the creative production area inside Canvas Notebook. It brings image and video generation into the same workspace as briefs, campaign notes, agent conversations, and final files.

Instead of treating every generation as an isolated prompt, Studio can reuse products, personas, styles, references, and presets. This supports consistent output across a campaign and makes successful production setups easier to repeat.

## Core capabilities

- Generate images from a prompt and selected format.
- Generate video with supported provider models.
- Use reference images and model references.
- Edit or transform existing images.
- Build reusable product, persona, and style models.
- Save repeatable generation settings as presets.
- Produce multiple line items through bulk generation.
- Adapt outputs to a different aspect ratio.
- Filter and review pending, completed, and failed outputs.
- Save selected results into the active workspace.

## A representative workflow

Create a product model with approved reference images, add a visual style for the campaign, and build a preset for a 4:5 social asset. Generate a small set of variations, review them with the campaign brief open in Notebook, then save the approved output into the project folder.

For a larger catalog, use bulk generation to apply the same production logic across multiple products. Track failures separately and regenerate only the affected line items.

## References and consistency

A clear prompt remains important, but references provide visual constraints that text alone cannot. Product references help preserve form and packaging. Persona and style references help control the subject and visual language. Presets collect settings that should be reused together.

Generated media is probabilistic. References improve consistency but do not guarantee exact product details, typography, hands, logos, or legal compliance. Review every asset before publication.

## Providers, cost, and files

Studio models require provider credentials configured in Settings. Available media types and controls depend on the selected provider and model. Generations may incur provider costs and can fail because of model limits, safety policies, invalid references, or temporary service issues.

Saving an output to the workspace turns it into a normal project asset that can be reviewed, downloaded, shared, or referenced by the agent.
