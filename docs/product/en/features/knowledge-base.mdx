# Markdown Knowledge Base

Canvas Notebook treats files as the durable foundation of the workspace. Markdown notes remain readable outside the application, work well with version control, and can be organized with normal folders instead of being locked inside a proprietary page database.

The Notebook combines the file explorer, editor, previews, agent chat, and terminal in one surface. The agent works with the same files you edit, so a brief written by a person can become input for research, production, automation, and reporting without being uploaded into a separate knowledge system.

## Core capabilities

- Create and edit Markdown with live rendering and auto-save.
- Organize knowledge with folders and real file paths.
- Link notes with Obsidian-style wiki links.
- Inspect backlinks and linked references.
- Add document properties and structured metadata.
- Embed related Markdown documents.
- Visualize linked documents in the Document Graph.
- Find unresolved links and missing relationships.
- Preview code, images, PDFs, Office documents, spreadsheets, presentations, HTML, audio, and video.
- Export or publicly share selected work when needed.

## A representative workflow

Create a folder for a client project with `brief.md`, `audience.md`, `research.md`, and `campaign-plan.md`. Link the audience and research notes from the brief. Ask the agent to read the connected material and update the campaign plan while preserving the original sources.

As the project grows, the Document Graph reveals which notes are connected and which references have not been resolved. Backlinks make it possible to see where an important decision or asset is being used.

## Files stay useful outside Canvas Notebook

Markdown is plain text. You can download it, process it with scripts, store it in Git, open it in another editor, or migrate it without a database export. Canvas-specific enhancements are designed around readable Markdown conventions rather than hidden document state.

Other file types remain part of the same workspace. Canvas Notebook can preview and work alongside documents, spreadsheets, presentations, media, Excalidraw boards, and Marp presentations even when Markdown remains the primary knowledge layer.

## Sharing and safety

Public file sharing is explicit. Active public links are reachable without login and should be reviewed in the Security area. Shared views are read-only, and the application checks file identity so missing or replaced files can be deactivated.

Do not store API keys, passwords, or integration tokens in knowledge-base documents. Use the protected integration and provider settings for secrets.
