# Troubleshooting Email Connections

Identify whether the failure concerns authorization, sending, mailbox reading, policy, message content, or AI runtime. These layers can fail independently.

## No mailbox or folders

Confirm the displayed address and workspace. If the account list could not load, choose Retry. If a shared mailbox is missing, ask an organization administrator to connect it and a workspace administrator to assign it; membership alone does not connect a mailbox. A custom account needs IMAP settings for inbox, reading, search, and organization; SMTP alone is send-only. Verify the IMAP host, port, secure mode, username, password, and provider-side IMAP access.

## Sending fails

Test SMTP or reconnect OAuth. Check From identity, recipient syntax, attachment size, account quota, provider rejection, and the `sendTo` policy. A policy error identifies the address that is not allowed. Shared manual sends and reviewed drafts remain in Outbox when sending fails. Open the failed item, correct the recipients or ask an authorized administrator to adjust the policy, then review and retry. If delivery is uncertain, check the provider Sent folder before doing anything that could send a duplicate.

## OAuth expired or revoked

Expired and revoked accounts remain visible. Choose the repair action, then Reconnect in personal account settings, or contact the shared mailbox administrator. Reauthorize the existing provider account or update SMTP/IMAP credentials. Disconnect is not required for repair and deletes the stored secret.

## AI drafting fails

Confirm an agent provider is ready, the selected workspace is accessible, context files use supported types, and input limits are not exceeded. Remove large or irrelevant context before retrying. The email connection can be healthy even when the AI model is not.

## HTML or remote content looks incomplete

HTML is sanitized and remote resources are controlled for privacy. Allow remote resources only for a trusted sender when they are necessary to understand the message.
