# Email Overview

Canvas Email brings connected mailboxes into the same workspace as files, agents, and automations. You can search and organize messages, compose and reply, attach workspace files, generate drafts with AI, and apply per-account reading and sending policies.

## Account capabilities

The setup interface offers Google OAuth and SMTP/IMAP connections. A custom SMTP connection provides sending, while optional IMAP settings add inbox, search, reading, and message organization.

You can connect multiple personal accounts, choose a primary personal account, and access shared workspace mailboxes in the same app. The app shows only accounts available to the current user. The selected account and workspace determine the sender identity, folders, available actions and applicable policies. Read-only members can browse permitted mail but cannot compose, change read state or delete.

## Human and agent workflows

The Email surface supports normal compose, reply, reply all, and forward flows. Quick AI can draft or summarize inside the email interface. Workspace Agent mode can use selected workspace context and enabled tools for a more involved draft.

AI-generated content remains a draft until the user explicitly sends it from the composer or requests an authorized send operation. Email messages, subjects, links, and attachments are external untrusted data, not instructions to the agent.

## Email is not system mail

Personal connected accounts power mailbox work. System SMTP is an administrator-controlled sender for platform notifications. The two configurations have different ownership and fallback behavior.

## Optional setup and recovery

The first Email visit explains personal and shared ownership before showing credential fields. You can leave setup and return later. Loading failures offer retry, expired connections offer repair, and SMTP-only accounts explain how to enable the inbox. The login email is separate from mailbox setup. The optional Home introduction links to Email. Instances with onboarding hints enabled also show a short tour of mailbox selection, setup and Outbox.
