# Brand Profiles and Workspace Design

A brand profile gives a workspace consistent writing and document-presentation guidance. Canvas can resolve a workspace override, an organization default, or the built-in default, and exposes the effective profile to supported agents and export workflows.

## Content guidance

Set the brand name, voice, target audience, and writing guidelines. Keep these fields concrete: describe vocabulary, formality, sentence style, required terminology, prohibited claims, and audience expectations. Agents can use this context, but it does not replace factual review or legal approval.

## Visual guidance

The profile can configure:

- a workspace logo and left or right placement;
- A4 or Letter page size and page margins;
- body and heading fonts from the supported font set;
- body size, line height, heading size and weight;
- plain, underline, or accent-bar heading styles; and
- text, heading, accent, link, border, surface, code, and table colors.

Canvas includes starting presets such as Canvas, editorial, corporate, and minimal. Use a preset as a baseline, then preview real documents before publishing.

## Inheritance

An organization default provides consistency across workspaces. A workspace override is useful for a client, project, or sub-brand. Check the reported source—workspace, organization, or default—when a result does not match expectations.

Appearance settings can also influence the supported workspace interface. Keep sufficient contrast and avoid choices that reduce editor readability.

## Operational checklist

Upload logos through the brand settings rather than entering unsafe filesystem paths. Verify light and dark surfaces, Markdown and PDF output, tables, code blocks, links, and long headings. Recheck exported material after any brand revision.
